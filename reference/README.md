# Reference photograph

`vrijheid-NG-MC-500.jpg` is the Rijksmuseum's photograph of its model of the Dutch
74-gun ship *Vrijheid* (Amsterdam, c.1782), object NG-MC-500, downloaded from
<https://iiif.micr.io/DQApr/full/2000,/0/default.jpg>. Rijksmuseum images of works in the
public domain are released without restriction.
<https://www.rijksmuseum.nl/en/collection/NG-MC-500>

It is a Dutch 74 of the generation before the Waakzaamheid, unrigged and unpainted except
for the wales and the port linings, so it is a check on proportion, the tops, the pole
topgallants and the stern and head — not on paint or sails. The `reference` camera in
`viewer/views.js` is matched to it; `python3 tools/compare.py reference-hero-furled.png`
lays a render beside it.
