# Waakzaamheid — parametric model

The Dutch 74 that chases the Leopard through the Southern Ocean in Patrick O'Brian's
*Desolation Island*, built for The Helmsman's Watch the way HMS Surprise is built in
`surprise-model`: a parametric generator, her hull lofted from a real draught, four
levels of detail, the same API.

**Status: research done, plan waiting for approval. No model code yet.**
